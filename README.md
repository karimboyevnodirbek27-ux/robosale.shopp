# RoboSale - Robotika Mahsulotlari Online Do'koni 🤖

O'zbekistondagi eng sifatli robotika mahsulotlari do'koni!

## 📦 Loyiha Tuzilishi

```
RoboSale/
├── frontend/           # React + Vite frontend
│   ├── src/
│   │   ├── components/ # Qayta ishlatiladigan komponentlar
│   │   ├── pages/      # Sahifalar
│   │   ├── context/    # React Context (Cart)
│   │   ├── data/       # Statik ma'lumotlar
│   │   └── assets/     # Rasmlar va ikonlar
│   └── public/
│       └── images/     # Mahsulot rasmlari
├── backend/            # Express.js backend
│   ├── config/         # Konfiguratsiya
│   ├── models/         # MongoDB modellari
│   ├── routes/         # API routelari
│   └── server.js       # Asosiy server
└── README.md
```

## 🚀 Ishga Tushirish

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend http://localhost:5173 da ishlaydi.

### Backend
```bash
cd backend
npm install
npm run dev
```
Backend http://localhost:5000 da ishlaydi.

### Ma'lumotlar Bazasini To'ldirish
```bash
cd backend
node seed.js
```

## 🛠 Texnologiyalar

### Frontend
- React 18
- Vite
- React Router DOM
- React Icons
- Vanilla CSS

### Backend
- Express.js
- MongoDB + Mongoose
- JWT (Authentication)
- bcryptjs (Password hashing)
